Definition Workflow

v2mom-company

Company-level V2MOM. The top of the cascade - defines organizational vision and strategic priorities that flow down to departments.

Specs in This Workflow

v2mom-measures Required source Quantifiable metrics. Each measure should map to KPIs in ProductContext.
v2mom-methods Required source Actions and initiatives. Each method should map to capabilities in ProductContext.
v2mom-obstacles Required source Known blockers and risks. Each obstacle should have mitigation strategies.
v2mom-values Required source Ranked list of beliefs and priorities. Higher-ranked values take precedence in trade-offs.
v2mom-vision Required source The north star - what we want to achieve. Should be inspiring, clear, and memorable.
v2mom-alignment Optional gtm Synthesized document showing alignment to parent V2MOM methods.
v2mom-summary Optional output Unified V2MOM document combining all sections with cross-references.

Synthesis Rules

How downstream specs are generated from upstream ones.

→ v2mom-alignment

Company V2MOM is the root - no parent alignment document needed.

v2mom-methods → v2mom-measures

Define quantifiable metrics for each method. For each measure: - Be specific and measurable (SMART) - Include baseline, target, and stretch goals - Define measurement frequency - Link to KPIs in ProductContext

v2mom-vision +v2mom-values → v2mom-methods

Define specific initiatives that advance the vision while honoring the values. For each method: - Link to ProductContext capabilities when applicable - Include clear ownership - Define success criteria - Estimate effort/timeline

v2mom-vision +v2mom-methods → v2mom-obstacles

Identify challenges that could block methods from succeeding. For each obstacle: - Categorize: technical, organizational, market, resource - Define mitigation strategies - Assign owner for resolution - Link to related decisions in ProductContext

v2mom-vision +v2mom-values +v2mom-methods +v2mom-obstacles +v2mom-measures → v2mom-summary

Create a unified V2MOM document with: - Executive summary - All five sections with cross-references - ProductContext entity links - Parent V2MOM alignment (if applicable)

v2mom-vision → v2mom-values

Extract the core beliefs and principles that will guide achieving the vision. Values should be: - Ranked in priority order (1 = highest) - Actionable trade-off guides ("customer success over short-term revenue") - Consistent with organizational values
