Definition Workflow Amazon Working Backwards

aws-product

Amazon Working Backwards methodology for new product lines. Starts with MRD, uses PR/FAQ-driven development with emphasis on customer obsession, ownership, and high standards.

Inspired by Amazon Working Backwards. The methodology is its originators’ own published work, drawn from their public writing and talks. ProductBuildersHQ has implemented it as a machine-readable workflow in specification-workflow-spec so it can be automated — spec synthesis and LLM-as-a-Judge evaluation via VisionSpec. This encoding is an independent interpretation, not affiliated with or endorsed by its originators.

Synthesis Rules

How downstream specs are generated from upstream ones.

MRD → BMC

Extract Business Model Canvas blocks from MRD. Focus on customer obsession and working backwards.

MRD +Press → FAQ

Challenge assumptions ruthlessly. Include internal stakeholder and customer questions.

MRD +Press +FAQ → 6-Pager

Amazon 6-pager format. Data-driven narrative, no slides.

MRD +Press +FAQ → PRD

Derive product requirements from market requirements. Map to customer segments.

MRD → Press

Write from customer perspective. Customer obsession is key.

MRD +PRD +UXD +TRD +TPD → SPEC

Unified specification consolidating all approved specs.

PRD +TRD → TPD

Test plan covering all PRD requirements with traceability.

PRD +UXD → TRD

Technical design to support PRD requirements.

Methodology Principles

Customer Obsession Start with the customer and work backwards
Ownership Think long-term, act on behalf of the entire company
Invent And Simplify Find simplifying assumptions, expect innovation
Are Right A Lot Seek diverse perspectives, disconfirm beliefs
Insist On Highest Standards Relentlessly high standards
Think Big Create bold direction, look around corners
Bias For Action Speed matters, two-way door decisions
Frugality Accomplish more with less
Earn Trust Vocally self-critical, benchmark against best
Deep Dive Stay connected to details, narratives expose gaps
Have Backbone Disagree and commit, truth-seeking over social cohesion
Deliver Results Focus on inputs, launch is the starting line

Feeds Execution Via

AWS Working Backwards → AI-DLC Definition side runs Amazon Working Backwards (aws-product) to produce the six-pager, PRD, and TRD; the execution side hands those to AWS AI-DLC, whose Requirements Analysis absorbs them as the Vision and drives Construction.
