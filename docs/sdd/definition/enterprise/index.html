Synthesis Rules

How downstream specs are generated from upstream ones.

MRD → BMC

Extract Business Model Canvas blocks from MRD sections 2-11. Format as standalone canvas for visual review.

MRD +Press → FAQ

Address customer questions based on segments, internal questions based on risks and assumptions.

MRD +Press +FAQ → PRD

Derive product requirements from market requirements. Map to customer segments.

MRD → Press

Write from customer perspective based on value propositions and customer segments in MRD.

MRD +PRD +UXD +TRD +TPD → SPEC

Unified specification consolidating all approved specs.

PRD +TRD → TPD

Test plan covering all PRD requirements with traceability.
