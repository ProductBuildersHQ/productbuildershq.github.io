VisionStudio

An LLM-powered desktop application for specification authoring and evaluation — an integrated workspace for creating, evaluating, and iterating on product specifications using the VisionSpec methodology.

Key Capabilities

  • Dual methodology selection: choose a requirements methodology (AWS Working Backwards, and others) and an implementation methodology (AIDLC, SpecKit) per project.
  • LLM-as-a-Judge evaluation: evaluate specs against profile rubrics, with a context-aware writing assistant to help close the gaps it finds.
  • AIDLC workflow: AWS's AI-Driven Development Lifecycle — Inception → Construction → Operations — with generated deliverables and phase gates to track completion.
  • Strategic planning: V2MOM cascades from organization to team to project, a visual capability stack, and a timeline roadmap view.
  • Maturity Model dashboards: framework-based maturity assessments, including SCALE.
  • DevX usage dashboard: sessions, prompts, commits, AI-assisted %, and cost, sourced from OmniDevX.

Product Tour

01

Spec Workflow

The Working Backwards pipeline at a glance: human-authored Market Requirements flow into LLM-generated vision documents — Press Release, FAQ, 6-Pager — then product, technical, and test specs, converging on a single Execution Spec. Every spec carries its evaluation status: pass, needs work, or fail.

02

Spec + LLM-as-a-Judge Evaluation

Each spec is judged in place. The evaluation panel sits beside the document with a categorical score, confidence level, blocking issues, and per-dimension breakdowns — requirements clarity, success metrics, dependencies, user stories — so revision targets are explicit, not vibes.

03

Findings Across the Workflow

The consolidated view rolls every evaluation up across the workflow: specs evaluated, passing and needs-work counts, findings by severity, and each blocking issue tied back to the exact section of the exact spec that raised it.

04

Initiative Execution

From spec to shipped: the PRISM dashboard — surfaced in VisionStudio — tracks initiatives, their phases, and stable roadmap items (RMIs) across repositories, with per-phase completion status and dependency tracking.

Why It Matters

As AI compresses the distance between intent and implementation, the bottleneck moves upstream — to how well a spec is written and judged before an agent ever touches code. VisionStudio is the applied tool for the VisionSpec methodology described on this site: it turns strategy, specifications, and delivery workflows into an operating system a ProductBuilder can actually run.
